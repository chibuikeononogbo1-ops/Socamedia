




# Soca Media

A full stack laravel social media web application built for seamless online connection, content sharing, and real-time interaction.

<img src="Home page (2).png" alt="Soca Home Page (2)">
<img src="profile page.png" alt="Soca profile Page">

##  Features
* **User Authentication:** secure sign-up, login, and profile customization.
* **Post Management:** create, edit, and delete text or image posts.
* **Social Interactions:** Like,comment on, and share posts from other users.
* **Network & Feeds:** Follow/unfollow users to curate a personlized news feed.
* **Responsive Design:** Optimized for both desktop amd mobile browsers.

## Tech Stack
* **Frontend** [HTML/CSS/JS]
* **Backend** [laravel PHP]
* **Database** [SQLITE]

## Getting statrted

1. **Clone the repository**
```bash
git clone https://github.com
```
2. **Install dependencies**
```bash
composer install
```
3. **Set Environment**
```bash
cp .env.example .env
```
4. **Run the application**
```bash
php artisan serve
```
